##Project Overview

This project is an interactive Coffee Sales Analysis Dashboard developed in Microsoft Excel to analyze coffee shop sales performance. The dashboard transforms raw transactional data into meaningful business insights using PivotTables, PivotCharts, Slicers, and Excel formulas.
It enables users to monitor sales trends, product performance, customer purchasing patterns, and location-wise revenue through an intuitive and interactive interface.
